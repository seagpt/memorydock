# Contributor Covenant Code of Conduct

We are committed to a welcoming, respectful, and harassment-free community. Be constructive, assume good intent, respect privacy, and never share another person's private data, credentials, or production artifacts.

Unacceptable behavior includes harassment, discriminatory language, doxxing, publishing secrets, or using the project to facilitate unauthorized access.

Report concerns through the repository's private security/advisory route. Maintainers may remove content or participation that violates these standards.
