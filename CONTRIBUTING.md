# Contributing

Thanks for helping improve this Docker setup.

## Before you open a pull request

- Keep it focused on running Supermemory Local in Docker.
- Do not add keys, private data, backups, or real logs.
- Do not change or imitate the Supermemory API.
- Run `./scripts/validate.sh`.
- Explain what you changed and how you checked it.

Please use an issue first for larger changes.
